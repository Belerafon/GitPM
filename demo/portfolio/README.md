# Демонстрационный портфель GitPM

Этот репозиторий наполнен через GitPM CLI. Все имена, проекты и адреса вымышлены.

Каталог `uploads/` предназначен для локальных входных документов. Его содержимое
игнорируется Git и не относится к данным демонстрационного портфеля.

Проект «Диагностика неполного плана» специально содержит длинное название этапа и
активные задачи без полной пары дат. Он служит демонстрационным сценарием устойчивости
диаграммы Ганта: шкала строится по этапам, не получает пустую вертикальную прокрутку,
а под ней перечисляются задачи, даты которых требуют внимания.
